# Sahil Shekh — portfolio

Personal portfolio for Sahil Shekh, an automotive diagnostic and electrical technician (fresher) from Deoria, Uttar Pradesh.

Built with React, TypeScript, Tailwind CSS, shadcn/ui-style components (Radix) and Motion. Deployed to GitHub Pages by GitHub Actions.

## Run it

```bash
npm install
npm run dev      # local preview
npm run build    # type-check and build into dist/
```

## Change the content

All text lives in `src/lib/data.ts` and comes from the resume. Replace `public/Sahil_Shekh_Resume.pdf` to update the download, and `public/portrait.webp` to change the photo.

## Deploy

Push to `main`. In the repository settings, open **Pages** and set **Source** to **GitHub Actions** once.
